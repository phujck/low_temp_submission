\section{Numerical implementation details}
\label{app:numerics_implementation}

This appendix specifies the numerical protocol used for
Sec.~\ref{sec:numerical}.

\subsection{System realization}

The simulation model is
\begin{align}
H_S&=\sum_{i=0}^{4}E_i\lvert i\rangle\!\langle i\rvert,\qquad E_0=0,\\
P&=\lvert 4\rangle\!\langle 4\rvert.
\end{align}
To avoid embedding hand-tuned level spacings in the manuscript, the nonzero
energies $(E_1,\ldots,E_4)$ are sampled once from a seeded random draw and then
kept fixed across all $(\beta,g)$ sweeps. In the code this is controlled by
\texttt{energy\_seed} in the run profile. For the default seed
\texttt{energy\_seed=20260212}, the resulting spectrum is
\begin{equation}
\begin{aligned}
E_0&=0, \\
E_1&=0.42848,\quad E_2=0.68725,\\
E_3&=1.47801,\quad E_4=1.91855.
\end{aligned}
\end{equation}

\subsection{Ohmic discretization}

The continuum target spectrum is
\begin{equation}
J_g(\omega)=2\eta g^2\omega e^{-\omega/\omega_c}.
\end{equation}
For each coupling $g$, we discretise the interval
$\omega\in[0,\omega_{\max}]$, $\omega_{\max}=\omega_c\times\text{omega\_max\_factor}$,
into mode bins with centres $\omega_k$ and widths $\Delta\omega_k$, then set
\begin{equation}
c_k^2=\frac{2}{\pi}J_g(\omega_k)\,\omega_k\,\Delta\omega_k.
\end{equation}
This ensures that the discretised reorganization scale
\begin{equation}
\lambda_{\mathrm{disc}}=\sum_k\frac{c_k^2}{2\omega_k^2}
\end{equation}
tracks the continuum expression
\begin{equation}
\lambda_{\mathrm{cont}}=\frac{1}{\pi}\int_0^\infty\frac{J_g(\omega)}{\omega}\,d\omega.
\end{equation}

\subsection{Exact and stochastic estimators}

The exact reference at each parameter point is
\begin{equation}
\rho_S^{\mathrm{ED}}=\frac{\Tr_B[e^{-\beta H_{\mathrm{tot}}}]}{\Tr[e^{-\beta H_{\mathrm{tot}}}]},
\end{equation}
computed with finite oscillator truncation and checked against increasing cutoff.

Two stochastic estimators are used:
\begin{enumerate}
\item HS-path: sample $\xi(\tau_j)$ on a finite imaginary-time grid from the
kernel covariance and set $X\approx\Delta\tau\sum_j\xi(\tau_j)$.
\item HS-scalar: sample $X\sim\mathcal N(0,C_\beta)$ with
$C_\beta=2\beta\lambda_{\mathrm{disc}}$ directly.
\end{enumerate}
Because $[H_S,P]=0$, both reduce to sampling the same scalar shift in the
projector sector.

\subsection{Normalization and reproducibility}

Every constructed state (ED, analytic, HS-path, HS-scalar) is explicitly
renormalised by $\rho\leftarrow\rho/\Tr(\rho)$ before computing observables.
Run metadata (profile, seed, runtime) is stored in the simulations run-manifest
JSON file.
